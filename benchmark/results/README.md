# Benchmark Results

This directory contains benchmark results generated by the csv-batch benchmark suite.

## Latest Results

- [All Benchmarks - Medium Dataset](./benchmark-results-all-medium-latest.md) - Complete parsing and database tests
- [Parsing Only - Medium Dataset](./benchmark-results-parsing-medium-latest.md) - Pure CSV parsing performance
- [Database Only - Medium Dataset](./benchmark-results-database-medium-latest.md) - Database import scenarios

## Result Format

Each benchmark report includes:

1. **System Information**: CPU, memory, OS, and Node.js version
2. **Benchmark Results**: Individual test results with performance metrics
3. **Summary**: Weighted scoring across all tests with placement rankings

## Scoring System

Our summary uses a weighted scoring system:
- **1st place**: 10 points
- **2nd place**: 8 points  
- **3rd place**: 6 points
- **4th place**: 4 points
- **5th place**: 2 points
- **6th+ place**: 0 points

## Running Benchmarks

```bash
# Generate new results
npm run benchmark              # All tests, saves markdown report
npm run benchmark parsing      # Parsing only
npm run benchmark database     # Database only
npm run benchmark sqlite large # SQLite with large dataset
```

Results are automatically saved as markdown files with timestamps for historical comparison.
